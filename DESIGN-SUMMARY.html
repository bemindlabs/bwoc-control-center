📍 TL;DR

StackTauri 2 (Rust core) + React 19 + Vite + shadcn/Tailwind v4 — desktop (mac/win/linux) + iOS/Android จาก codebase เดียว
Backendbwocd daemon ใหม่ (standalone, Rust/axum) ห่อ bwoc … --json · bind 127.0.0.1:10130 · เปิดผ่าน tailnet (tailscale serve HTTPS) — ไม่มีพอร์ต public
Auth2-factor principal: SSO/Google (คน, รวม identity กับ bwoc-party) + ed25519 device key (เครื่อง) — bind กันตอน enrollment ผ่าน QR
จุดต่างapp ตัวแรก ของ ecosystem ที่ cross-platform + remote-over-tailnet — ระยะยาว replace bwoc-mcc + bwoc-devices-app

bwocd standalone (Rust/axum)

D2 · Auth
ed25519 signed requests เต็มรูปตั้งแต่ MVP
ลอก bwoc-party pattern (JCS canonical + nonce/timestamp) — ไม่มี token-only shortcut
D3 · Scope
Replace bwoc-mcc + bwoc-devices-app
consolidate desktop surfaces → retire ทั้งสองเมื่อ control-center พร้อม
D4 · Frontend
React 19 + Vite + shadcn/Tailwind v4
ลอก components/stack จาก bwoc-party ได้ตรง
D5 · Multi-host
Multi-host ตั้งแต่ MVP
host-list + /hosts เฟส 1 — สลับดู anna ↔ busaba, architecture ถูกตั้งแต่แรก
D6 · Daemon hosts
bwocd บนทั้ง anna (launchd) + busaba (systemd)
แต่ละ host มี daemon + tailscale serve ของตัวเอง — คุมทั้งสอง workspace จากมือถือ
D7 · iOS delivery
Ad-hoc / dev device
ลง iPhone จริงผ่าน tailnet ตั้งแต่เฟส 1 (มี dev account + UDID พร้อม)
D8 · Enrollment
QR จาก desktop ที่ trust
desktop local เป็นตัวออกใบรับรองให้ device ใหม่ — UX ดีบนมือถือ
D9 · Port + repo

bemindlabs/bwoc-control-center = Tauri app + bwocd (party=10120, ต่อเนื่อง)
D10 · SSO
SSO เต็มรูป รวม identity กับ party
Google client + Actor เดียวกันทั้ง ecosystem — ประกอบกับ device key เป็น 2-factor
D11 · SSO phasing
SSO enrollment เต็มตั้งแต่เฟส 1
Google login + QR grant + binding ใน MVP เลย ไม่มี stub owner — auth ถูกแต่แรก ไม่ต้อง migrate
D12 · watchOS
watchOS companion — glanceable read-only (เฟส 3)
native SwiftUI target ใน Xcode project เดียวกัน (Tauri ไม่ target watchOS) · watchOS ไม่มี VPN/tailnet → iPhone เป็น relay ผ่าน WatchConnectivity, ไม่เปิด public แทน · complication + notification forwarding ฟรีจาก iOS

🔐 Auth Model — 2-factor principal

🧑 SSO / Google (OIDC)ยืนยัน คน — human Actor รวมกับ bwoc-party · ทำงานหนักตอน enrollment + revocation · bwocd verify แบบ stateless (JWKS) ไม่พึ่ง party uptime
🔑 ed25519 device keyยืนยัน เครื่อง — เก็บใน Keychain/Keystore · เซ็น ทุก request (header X-BWOC-* เหมือน party) · device key = session ที่ผูกกับคนแล้ว
Layer ความปลอดภัย: tailnet (device ในเครือข่ายเท่านั้น) → signed request (identity + กัน replay) → role (owner/operator/viewer) → per-action confirm สำหรับ destructive ops (เฟส 2)

🚀 Roadmap

เฟส 1 MVP

  • bwocd read-only + ed25519 verify เต็ม
  • SSO enrollment เต็ม: Google login + QR grant + binding
  • Tauri app: Transport trait (LocalShell/RemoteHttp), host-list (anna+busaba)
  • หน้าจอ: Fleet → Agent detail → Inbox (read)
  • Ship จริง: macOS .dmg + iOS ad-hoc
  • Demo = iPhone นอกบ้านเห็น fleet 2 host สด

เฟส 2 Actions

  • Mutations: send / spawn / stop / retire
  • Per-action confirm + biometric
  • SSE log streaming · chat (chat_proto)
  • Multi-operator roles + revocation UI
  • Party Actor cross-link

เฟส 3 Consolidate

  • Config editing (manifest / .env / routes)
  • Gateway / party / inbox monitor
  • Ollama model management
  • Devices / MQTT → กลืน mcc + devices-app
  • ⌚ watchOS companion (SwiftUI, iPhone relay)
  • Web build (OIDC per-session)
